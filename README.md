\## 📱 Installation



1\. Open the \*\*Join the Channel\*\* link above.

2\. Sign in with your Samsung / SmartThings account if required.

3\. Join the `JYPs Self SmartHome` channel.

4\. Open the SmartThings app.

5\. Find the device you want to install or update.

6\. Select the corresponding Edge driver.

7\. Install or switch to the driver.



The exact installation flow may vary depending on the SmartThings app version and device status.
